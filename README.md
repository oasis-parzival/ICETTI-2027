# ICETTI-2027

## International Conference on Emerging Trends in Technologies for Industry

**Date:** 4th & 5th June 2027  
**Venue:** SIES Graduate School of Technology, Navi Mumbai

This is the official website for the ICETTI-2027 conference. It is built using React, Vite, and Tailwind CSS.

### Features
- Modern, responsive design (Cyber Industrial aesthetic)
- Animated mesh backgrounds and floating particles
- Interactive conference tracks and committee sections
- Detailed registration and paper submission guidelines

### Development
To run the project locally:

```bash
npm install
npm run dev
```

### Deployment
The project is optimized for deployment on platforms like Netlify or Vercel.
- Build command: `npm run build`
- Output directory: `out`
- Redirects are handled via `public/_redirects` for SPA routing.
